## O que funciona nesta versão estática

- Página premium TRIDRA 3D / TRIDRA Lab
- Portfólio
- Loja/catálogo
- Carrinho com armazenamento local no navegador
- Cadastro/login demonstrativo com armazenamento local no navegador

- Escolha demonstrativa de pagamento por Pix/cartão

## Para produção real

GitHub Pages é hospedagem estática. Para login real, pedidos reais e pagamento real, usar o pacote completo Next.js + Supabase + Mercado Pago criado anteriormente.

Nunca publicar tokens privados do Mercado Pago, Supabase Service Role ou outras credenciais dentro do HTML público.
